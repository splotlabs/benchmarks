# splot benchmarks

Reproducible benchmark harness for AV2 decoders: Splot, dav2d and avmdec.

This repository is new. The harness is not implemented yet and no results exist.
The work is tracked in [splotlabs/splot#2046](https://github.com/splotlabs/splot/issues/2046).
